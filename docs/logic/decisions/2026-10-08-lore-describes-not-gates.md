## Context

The codex and the brand bible said a member advances a clearance by meeting Shell Hardness, Pincer Torque, and Submergence Depth thresholds, and that Gems and Credits unlock at set clearances. The product derives stage and clearance from lifetime XP, starts every profile with both currencies, and opens the market to everyone. The two sources had drifted apart.

## Decision

Lore describes the world and the code defines the mechanics. Stage scriptures show the metrics as typical readings at each stage, with no gate language and no currency unlock points. Real thresholds live in code and this atlas. AGENTS.md states this as a hard rule.

## Alternatives

Rewriting the canon around XP, which would put changing numbers into scripture. Rebuilding progression around the three metrics, which is a large product change with no current need.

## Consequences

Changing an XP threshold never requires a canon edit. The Pipeline page still shows readings per clearance, now under "The rite" instead of "Requirement".
