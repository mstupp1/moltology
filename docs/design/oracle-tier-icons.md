# Oracle tier icons

Original raster product marks generated with the built-in ImageGen tool, November 2, 2026. Both use a silver-white shell-and-pearl visual language. Lite is a crescent shell; MAX is a three-plate armored core. Vendor logos remain separate and appear only beside admin model details.

The picker uses 128px transparent PNGs with WebP twins through `getAssetUrl`:

- Lite: `images/ui/oracle/oracle-lite-shell-v1.png`
- MAX: `images/ui/oracle/oracle-max-core-v1.png`

Full-resolution local sources and generation prompts are retained in ignored `tmp/oracle-icons-v1/`. The generated designs replace the earlier chevron marks. New designs should use versioned keys.

## Generation prompts

A distinctive compact curled deep-sea shell cradling one luminous pearl: a bold, slightly asymmetric crescent shell silhouette wrapping an off-center circular core, with just one broad clean negative-space spiral channel. Premium restrained futuristic marine identity for a dark ocean interface. Flat silver-white monochrome with crisp clean vector-like edges; no gradients, texture, shadows, glow, beveling or background. Icon must remain striking and readable at 20 pixels: broad solid forms, simple negative space, no thin detail. The visible icon fills 82% of the image square with even padding. Organic sculpted curves, confident professional brand design, distinctive silhouette, calm energy. This is an ORIGINAL product tier icon, not the Moltology logo or any vendor logo. No chevrons, arrows, brackets, hexagon border, letters, words, numbers, crowns, chip or generic circuit motif, no extra symbols. True transparent alpha background.

### MAX
