## Authoring Guidelines for New Canon

1. **Use the Template**: Every new scripture **must** be created using [scripture_template.md](TEMPLATES/scripture_template.md).
2. **YAML Frontmatter Rules**:
   - `id`: Unique identifier formatted as `SCR-XXX`.
   - `stage_clearance`: Minimum access tier (`1` through `4`).
   - `synaptic_weight`: Importance float between `0.1` and `5.0`.
3. **Tone & Aesthetics**:
   - Deep-Ocean Sci-Fi / Cyberpunk HUD combined with Biomechanical Rigor.
   - High data density, brutalist clarity, uncompromising commitment to biological shedding.
