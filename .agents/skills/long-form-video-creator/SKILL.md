# Long-form video creator

Before starting, read and follow [content worktree hygiene](../../../docs/content-worktree-hygiene.md) and the [content prerequisites](../../../content/README.md#shared-prerequisites).

A long-form video is an `episode.json` in `content/academy/videos/<slug>/`. The narration is the spine: every line is voiced first, then each picture is placed on the words it illustrates, so editing a sentence re-times the picture with it. `npm run longform:create` does the voicing, the cast renders and the final Remotion render. Nothing is generated by a video model.

Read before writing: `STYLE_GUIDE.md`, `BRAND_BIBLE.md`, the [writing playbook](../../../content/writing-playbook.md) (loudness 2 for long-form) and, for the cast, [animated-lessons](../animated-lessons/SKILL.md) and its [lesson format](../animated-lessons/references/lesson-format.md): character beats use the same shots, poses, looks and reactions. Before writing Remotion code, read [remotion-best-practices](../remotion-best-practices/SKILL.md) (installed with `npx remotion skills add`).

`content/academy/videos/what-is-moltology/episode.json` is the complete reference episode.

## 1. Script first, and get it approved

1. **One promise.** Write down what a stranger can do or understand after the video. A topic for YouTube maps to a validated outlier from the [youtube-research](../youtube-research/SKILL.md) skill; an Academy-only lesson follows its course.
2. **Pitch three hooks** with the playbook's scores, build the winner. The first line names something concrete in under two seconds. Real facts make the strongest hooks.
3. **Promise, Proof, Plan** in the first 30 to 45 seconds: restate what the video delivers, why to trust it (a cited fact, the Codex), and what it covers.
4. **Chapters.** Five to eight, each one idea. Open a loop early, close it late, turn once.
5. **Length.** The narrator reads about 165 words a minute at the long-form pace. 5 minutes is about 600 to 700 spoken words plus graphics holds and the 20-second end screen. Stills and graphics are cheap, so length costs mostly voice.
6. **Lore.** Introduce each term once, explained in the same sentence. Facts, stages and rules come from `BRAND_BIBLE.md` and `docs/logic/`, never invented. No economy rundown beyond "free to join".
7. **Real-world claims get real sources.** Open the source, add it to `sources`, and show it on screen with `props.source` on the beat that makes the claim. Never claim more than the source says.
8. **Ending.** One invitation (the free Moltmaxxing Audit, the site, the next lesson if it exists), then the end card, which holds 20 seconds for YouTube end-screen elements.

Write the script for review as a Claude Doc (pitches, a table per chapter of who, line and picture, then checks and sources), and in `episode.json`. Don't voice or render until the person approves the script.

## 2. The episode file

```json
{
  "id": "what-is-moltology", "title": "What is Moltology", "format": "long-form", "loudness": 2,
  "narrator": "oracle", "cast": ["juno", "kit", "moss"],
  "sources": [{ "id": "carcinization", "label": "Wolfe, Luque & Bracken-Grissom, BioEssays (2021)", "url": "https://doi.org/…", "supports": "…" }],
  "chapters": [{ "title": "Cold open", "beats": [{ "speaker": "narrator", "line": "…", "visual": { "kind": "motion", "component": "FamilyTree", "props": { … } } }] }]
}
```

A beat is one or two sentences and one picture. `speaker` is `narrator` (the Oracle, off screen) or a cast member, who must be in that beat's cast. Picture kinds:

| Kind | Fields | Made by | Use for |
| --- | --- | --- | --- |
| `character` | `set`, `cast`, `shot`, `move`, `focus`, `pose`, `look`, `acting`, `react`, `note` | `anim:create` at 1920x1080, lip-synced | The cold open, dialogue, reactions, the ending. The highest-value beats: about a quarter to a half of the video |
| `motion` | `component`, `props` | Remotion components in `video/motion/` | Titles, numbers, comparisons, diagrams, 3D. Each piece lands on the word that names it |
| `still` | `image` (under `media/`), `prompt` | Codex, Luna at low effort | Moods and places: a desk at night, a gathering. A whole slide can be a still when it's only text and art |
| `screen` | `capture` (file in `media/screens/`) | The real app, from `mockup-capture` or a recording | Showing a feature the line names |

Character beats in a row on the same set with the same cast render as one clip, so the cut between speakers is seamless and the voices keep their turn gaps. Narrator lines inside such a run are voiced by the Oracle over the cast.

### Motion components

| Component | Props | Lands on |
| --- | --- | --- |
| `TitleCard` | `title`, `eyebrow`, `plate` (a set name; uses its wide plate) | Fades in |
| `WordReveal` | `word`, `gloss`, `source` | Types the word as it's said |
| `FamilyTree` | `branches` | Each branch name, then "same" |
| `MeltDay` | `tabs`, `started` | "Forty", "ping", "Four", "tired" |
| `PingWaves` | | "Melt" |
| `MeltVsMolt` | | "same", rows in turn (rows from `src/lib/moltmaxxing-content.ts`) |
| `ShellTurntable`, `ShellSplit` | `cast` | "grow"; "splits", "climbs" (the real cast character and a glassy copy of its shell) |
| `MoltCycle` | `steps`, `cues`, `source` | Each step's cue word |
| `FourMoves` | | "Shed", "Harden", "Grip", "deep" |
| `ThreePanels` | `panels`, `cues`, `pill`, `pillCue` | Each cue word |
| `StageLadder` | | Each stage name, then "earned" |
| `EndCard` | `url` | Holds for the end screen |

A new graphic is a component in `video/motion/`, registered in `MOTION` in `video/Episode.tsx` and in `scripts/create-longform.ts`. Rules: everything moves from `useCurrentFrame()` (no CSS animation, no `useFrame`), time pieces with `cueAt(useBeat(), word)` so they follow the voice, colours and type from `video/theme.ts` (the site's tokens, Inter and Space Grotesk, weight 500 at most, sentence case), and nothing within 72px of the frame edge. Check new graphics in Studio with `npm run video:studio` (the Draft composition plays the whole episode with estimated timings) before rendering.

## 3. Art

Images go to Codex on Luna at low effort (medium only when it must pick between references or compose a shot). Write one brief with every prompt and exact save path, then run it in the background:

```bash
codex exec --skip-git-repo-check -s workspace-write -m gpt-6-luna -c model_reasoning_effort=low "$(cat brief.txt)" </dev/null
```

Each prompt starts from the set art style in `content/animation/sets/art.json`. Files go in `content/academy/videos/<slug>/media/` (git-ignored; the Academy ingest uploads finished media):

- `plates/<set>.png`: a 16:9 painted plate for each set a character beat uses (the 9:16 kits crop badly). The set's `plate` prompt, rewritten as wide, with an empty floor in the lower third and nothing in front.
- `stills/<name>.png`: the still beats, from their `prompt`.
- `screens/<capture>.png`: app captures. The marketing previews (`/images/marketing/<id>_desktop_preview.webp`) are a fine first pass; record the real feature when the line is about a specific moment.

Codex returns about 1672x941 for 16:9; the render scales to fit. Look at every image before using it: no characters, text or clutter where the cast will stand.

## 4. Voice, render and check

```bash
# Plan only: estimated timings, no voice cost, no render
npm run longform:create -- --episode content/academy/videos/<slug>/episode.json --silent --no-render
# A sample chapter at draft quality, voiced
npm run longform:create -- --episode <file> --chapters 1 --scale 0.5 --draft
# The full video
npm run longform:create -- --episode <file>
```

The narrator is the Fish voice `Oracle` (`scripts/lib/tts-providers/fish-audio.ts`), the same in every video; characters use their `cast.json` voices. Long-form takes run at normal pace (`+0%`). Takes are cached by line and voice in `tmp/longform/<id>/voice/` and cast clips by their direction, so a re-run re-voices and re-renders only what changed. If the `Oracle` entry is ever pointed at another Fish voice, delete `tmp/longform/<id>*/blocks/` too: anim:create caches its takes by voice name.

Output in `tmp/longform/<id>/`: `final.mp4` (1920x1080, 30 fps), `captions.srt`, `chapters.txt` (YouTube chapter list, first at 0:00), `contact-sheet.jpg` (one still per beat) and `public/timeline.json`.

Check before calling it done:

- Watch the whole file once with sound, then the contact sheet. Every graphic lands on its word, no beat sits still for more than five seconds, the speaker is in frame for each character line, and the source credit shows on every real-world claim.
- Lip sync on the character beats (see animated-lessons' mouth check).
- The music sits under the voice, never over it.
- Run the playbook's boredom check on the render, not just the script.

Work in rounds like the music-video studio: script, sample chapter, full draft (`--scale 0.5 --draft`), notes, full render. Render full quality on the Mac; it's slow in the cloud.

## 5. Publish

Only with the person's go-ahead:

- **Academy:** hand `final.mp4`, the transcript (the script's lines) and `captions.srt` to [academy-course-creator](../academy-course-creator/SKILL.md) as a video lesson. It stays a draft until they say publish.
- **YouTube:** write `content/academy/videos/<slug>/youtube.md` (Title, Thumbnail, Description, Pinned comment and Settings sections; see the What is Moltology one): title and thumbnail from the youtube-research formats, description with the chapters from `chapters.txt` and the sources, every moltology.org link through `youtubeLink()` (`src/lib/attribution.ts`). Render the thumbnail from the `Thumbnail` composition (`npx remotion still Thumbnail tmp/longform/<id>/thumbnail.jpg --public-dir=tmp/longform/<id>/public --props='{"text":"…","plate":"plates/<set>.png"}'`). Then `npm run longform:publish -- --episode <file>` (`--dry-run` first) archives the files in Drive and uploads through Zernio as private, Education, not made for kids, with synthetic media disclosed. Zernio can't upload captions or pin comments: add `captions.srt` and pin the comment in YouTube Studio. The person makes it public.
- **Shorts:** two or three cut-downs re-made at 9:16 from the strongest character beats with `anim:create`, each ending on "full video on the channel".
