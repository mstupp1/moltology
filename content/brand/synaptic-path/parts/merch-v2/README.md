# Approved Moltology merch wordmark

Outlined from the site's Space Grotesk bold font (`public/fonts/space-grotesk-latin-bold.woff2`).
Title: `Moltology` at 200 source pixels. Caption: `THE SYNAPTIC PATH` at 80 source pixels,
tracked to the title's advance width. The caption begins 54 source pixels below the title's
lowest descender, with 20 pixels of canvas padding. Text is converted to paths, so print
rendering does not depend on installed fonts.

- White mug: emblem on one face, stacked text on the opposite face.
- Black tee: large red emblem above the stacked text.
- Light text uses `#f3f7f5` and `#a9b5b1`; dark text uses `#0f1414` and `#52615f`.

The exact placements and per-size print canvases live in `scripts/merch/designs.ts` under
`mug-moltology-v2`, `mug-moltology-v2-15oz`, and `tee-moltology-v2`. Keep the original
Synaptic Mark products/artwork intact for existing orders; this revision has new product
and variant IDs.
