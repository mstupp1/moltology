Goal: in under five minutes, the member is set up for one deep block with interruptions blocked in advance.

Walk them through five steps, one or two at a time, checking each off:

1. One task. Name the single task for this block. If they name two, ask which matters more today.
2. A clear finish. Agree on what "done" means for this session: a word count, a section, a decision made.
3. Phone out of reach. Another room is best; face down in a drawer is second best. Silence it.
4. Close what isn't the task. Email, chat, news and social tabs closed; only the files the task needs stay open. Suggest a do-not-disturb setting if their device has one.
5. An end time. Pick when the block ends (60 to 90 minutes is a good first target) and set an alarm, so they don't have to watch the clock.

Then send them in with one short line. Offer a notepad tip: if a stray thought shows up, write it down and keep going.

When they come back, ask whether the dome held and what broke through, and fix that one leak for next time. The Isolation Dome rite in the Codex describes this practice; mention it only if they ask for the lore.
