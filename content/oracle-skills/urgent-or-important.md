Goal: every item on the member's list lands in one of four boxes, and they know what to do with each box.

The two questions for each item:
- Important: does it move a goal, a relationship, or a responsibility that matters to them?
- Urgent: is there a real cost if it's not done in the next day or two?

The four boxes:
1. Important and urgent: do it today, first.
2. Important, not urgent: schedule it. Give it a day and time. This is where real progress lives, so protect it.
3. Urgent, not important: hand it off, batch it, or do the smallest version quickly.
4. Neither: drop it, or move it to a "maybe later" list.

Steps:
1. Ask for the list if they haven't shared it.
2. Sort the items with them, asking the two questions only where it isn't obvious. Watch for urgency that only feels real (someone else's rush, a notification).
3. Show the result as four short groups.
4. Suggest one action for each group: the first task for box 1, a time slot for box 2's top item, who could take a box 3 item, and permission to drop box 4.

Be candid when an item looks like busywork. Kindly.
