### Expressive Character Customization
- Guests can customize a starter character and automatically keep it when they create an account.
- Added full-body poses, reactions, shell details, size sliders, and instant color updates to the 3D character studio.
- Replaced the large stats card with a compact Moltmax stat bar and an interactive stat guide showing what each gear slot boosts.

### Oracle Launcher and Skills
- Added a dedicated Synaptic Core launcher for the Oracle, opening as a smooth slide-up panel on phones.
- Added Oracle skills to the Shop and a quick slash menu inside chat so you can launch structured methods like focus rounds or weekly reviews.

### Simpler Menus and Support
- Moved daily alignment tasks into the account menu and gave phones a full-screen account and public navigation menu.
- Streamlined Support into a single message box with automatic topic sorting.
